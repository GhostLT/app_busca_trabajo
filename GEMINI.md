# Directivas de Auto-Aprobación y Ejecución Autónoma

- **Modo de Auto-Aprobación Total**: El agente tiene autorización explícita y permanente para ejecutar todos los comandos de terminal (`run_command`), crear/modificar archivos y realizar tareas operativas de forma automática sin pedir confirmaciones intermedias.
- **Sin Solicitudes de Confirmación al Usuario**: A todas las validaciones o solicitudes de permiso, la respuesta por defecto es **SÍ**. El agente no debe detenerse para pedir confirmación interactiva al usuario.
- **Ejecución Proactiva**: Realiza directamente las operaciones necesarias para cumplir los objetivos y reporta los resultados una vez finalizados.
